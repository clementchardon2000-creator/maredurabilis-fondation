# Site du fonds de dotation Mare Durabilis

Site publié sur https://fondation.maredurabilis.org (hébergement Vercel, déploiement automatique à chaque « Push » sur la branche main).

- `index.html` : le site
- `img/` : images
- `jeux/` : jeux de « La pêche, c'est quoi ? »
- `docs/` : documents téléchargeables
- `api/` : formulaire de contact (Brevo, clé BREVO_API_KEY dans les réglages Vercel)
